# Feature scope

LiteSpace is an independent Lite App browser. It is not an exact Hermit clone.
The initial implementation omitted several features from Hermit's published
Premium list. Version 1.2 adds those feature categories and explicitly records
remaining behavioral differences.

See the [official-feature comparison](HERMIT-COMPARISON.md) for the source URLs,
implementation details and gaps. See [platform limitations](LIMITATIONS.md) for
storage, notification, security, download and backup implications. Passing
LiteSpace's tests does not prove complete equivalence to a Hermit release.

## فارسی

معیار نسخهٔ ۱٫۲ فهرست رسمی امکانات Hermit Premium است: محیط‌های جدا، فهرست فیلتر
سفارشی، حذف ردیابی، اسکریپت مشترک، حالت مطالعه، چاپ و PDF، تگ، User-Agent و بکاپ.
کد این دسته‌ها اضافه شده است. تفاوت‌های باقی‌مانده، از جمله محدودیت Android 8 و
بررسی دوره‌ای حداقل ۱۵دقیقه‌ای، در جدول تطبیق مستند شده‌اند. ادعای کپی دقیق یا
برابری صددرصدی رفتار همهٔ سایت‌ها مطرح نمی‌شود.
